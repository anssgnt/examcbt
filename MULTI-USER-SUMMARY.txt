                              MASALAH UTAMA
================================================================================

Saat siswa A selesai ujian dan logout, kemudian siswa B login, jadwal ujian 
siswa B masih menampilkan STATUS UJIAN SISWA A (misal: "Lihat Nilai" padahal 
siswa B belum ujian).

ROOT CAUSE: 4 Penyebab Utama
1. Cache jadwal tidak di-filter berdasarkan kelas user
2. State.schedules tidak di-clear saat logout
3. Status "SELESAI" di-reset global (tidak perlu)
4. State.schedules tidak di-clear saat login baru

================================================================================
                              SOLUSI DITERAPKAN
================================================================================

✅ FIX 1: Filter Kelas di renderMobileSchedule()
   File: mobile-core.js (Line 75-90)
   - Hanya tampilkan jadwal sesuai kelas user
   - Support multiple kelas: "10A,10B,10C"
   - Support "SEMUA" atau "ALL" untuk jadwal global

✅ FIX 2: Strip Status dari Cache Lokal
   File: mobile-core.js (Line 87-95) + script.js (Line 2197-2210)
   - Status dari cache di-reset berdasarkan waktu saja
   - Status "SELESAI" dari user lain tidak terbawa
   - Server fetch memberikan status akurat per-siswa

✅ FIX 3: Clear State Lengkap Saat Logout
   File: mobile-core.js (Line 464-475)
   - Clear State.user = null

✅ FIX 4: Clear State Saat Login Baru
   File: script.js (Line 1928-1960)
   - Clear State.schedules = []

   - Clear localStorage dari user lain

✅ FIX 5: Ownership Validation

   - Memudahkan detect stale data

================================================================================
                              ALUR APLIKASI
================================================================================

LOGIN FLOW:
1. User pilih nama siswa
2. Click "Konfirmasi"
3. Clear State.schedules, State.user, localStorage (user lain)
4. Set State.user = siswa baru
5. loadSchedules() dipanggil
6. Load dari cache lokal (filter kelas + strip status)
7. Fetch dari server (status akurat)
8. Set State._schedulesForUserId = siswa baru
9. Render jadwal untuk siswa baru

LOGOUT FLOW:
1. User click "Logout"
2. Clear State.user = null
3. Clear State.schedules = []
4. Clear State._schedulesForUserId = null
5. Clear localStorage (CBT_SUBMITTED_*, CBT_${userId}_*)
6. renderMobileSchedule() dipanggil
7. State.user = null → tidak ada filter kelas
8. Tampilkan empty state atau preview

RENDER FLOW:
1. renderMobileSchedule() dipanggil
2. Jika State.schedules kosong:
   - Load dari cache lokal
   - Filter berdasarkan State.user.kelas
   - Strip status (hanya berdasarkan waktu)
3. Jika State.user = null:
   - Tampilkan semua jadwal (preview) atau empty state
4. Render dengan status yang sudah di-filter
