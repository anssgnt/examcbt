================================================================================
  QUICK START - NETLIFY (40 MENIT)
================================================================================

Step 1: Prepare Files (5 min)
  - Copy optimization files to public/ folder
  - Create netlify.toml (already created)
  - Update exam.html with script tags

Step 2: Push to Git (5 min)
  git add .
  git commit -m "Deploy to Netlify"
  git push origin main

Step 3: Deploy (5 min)
  - Go to https://app.netlify.com
  - Click "New site from Git"
  - Select repository
  - Deploy

Step 4: Verify (5 min)
  - Check site loads
  - Check DevTools Console
  - Verify Service Workers

Step 5: Monitor (5 min)
  - Check Analytics
  - Check Performance
  - Monitor errors

Step 6: Update HTML (10 min)
  - Add script tags (see HTML-UPDATE-TEMPLATE.md)

Total: 40 menit

================================================================================
  QUICK START - LARAGON (20 MENIT)
================================================================================

Step 1: Run Setup Script (2 min)
  cd c:\laragon\www\cbtmo
  setup-infrastructure.bat

Step 2: Install Redis (5 min)
  choco install redis

Step 3: Start Services (1 min)
  startup.bat

Step 4: Update HTML (5 min)
  - Add script tags to exam.html

Step 5: Verify (2 min)
  - Open http://localhost/exam.html
  - Check DevTools Console

Step 6: Database Optimization (5 min)
  psql -U postgres -d cbtmo_db -f db-optimization.sql

Total: 20 menit
