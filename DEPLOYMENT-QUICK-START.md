# 🚀 DEPLOYMENT QUICK START GUIDE\n\n## Cara Deploy ke Production\n\n### 📋 Overview\n- **Total Time:** 2-3 hari\n- **Risk Level:** Low (backward compatible)\n- **Rollback Time:** <5 menit\n- **Downtime:** 0 menit (zero-downtime deployment)\n\n---\n\n## 🔧 QUICK DEPLOYMENT STEPS\n\n### STEP 1: PREPARE SERVER (30 menit)\n\n```bash\n# SSH ke server\nssh user@your-server.com\n\n# Create backup\ncp -r /var/www/cbtmo /var/www/cbtmo-backup-$(date +%Y%m%d)\n\n# Create directories\nmkdir -p /var/www/cbtmo/modules\nmkdir -p /var/www/cbtmo/logs\n```\n\n---\n\n### STEP 2: DEPLOY PHASE 1-4 (1 jam)\n\n#### 2.1 Upload files\n```bash\nscp *.js user@server:/var/www/cbtmo/\nscp modules/*.js user@server:/var/www/cbtmo/modules/\n```\n\n#### 2.2 Update exam.html\nTambahkan sebelum `</body>`:\n\n```html\n<!-- Phase 4: Advanced Service Worker & Caching -->\n<script src=\"/predictive-cache.js\"></script>\n<script src=\"/differential-sync.js\"></script>\n<script src=\"/data-compression.js\"></script>\n<script src=\"/exam-advanced-integration.js\"></script>\n\n<!-- Register Advanced Service Worker -->\n<script>\n  if ('serviceWorker' in navigator) {\n    navigator.serviceWorker.register('/sw-advanced.js')\n      .then(reg => console.log('✅ SW registered'))\n      .catch(err => console.error('❌ Error:', err));\n  }\n</script>\n```\n\n#### 2.3 Run database migrations\n```bash\npsql -U postgres -d cbtmo_db < db-optimization.sql\n```\n\n#### 2.4 Verify\n```bash\ncurl -I http://localhost/sw-advanced.js\n# Should return: 200 OK\n```\n\n---\n\n### STEP 3: DEPLOY PHASE 5 (1 jam)\n\n#### 3.1 Upload module files\n```bash\nscp modules/*.js user@server:/var/www/cbtmo/modules/\n```\n\n#### 3.2 Update exam.html\nTambahkan sebelum `</body>`:\n\n```html\n<script type=\"module\">\n  import { moduleLoader } from '/modules/loader.js';\n  await moduleLoader.preload(['core', 'ui', 'api', 'exam']);\n  console.log('✅ Modules loaded');\n</script>\n```\n\n#### 3.3 Verify\n```javascript\n// Buka DevTools → Console\n// Jalankan:\nmoduleLoader.load('core')\n// Harus return: Promise\n```\n\n---\n\n### STEP 4: DEPLOY PHASE 6 (1 jam)\n\n#### 4.1 Upload database files\n```bash\nscp db-*.js user@server:/var/www/cbtmo/\n```\n\n#### 4.2 Run optimization\n```bash\npsql -U postgres -d cbtmo_db < db-optimization.sql\n```\n\n#### 4.3 Setup Redis (optional)\n```bash\nsudo apt-get install redis-server\nsudo systemctl start redis-server\n```\n\n#### 4.4 Verify\n```bash\nredis-cli ping\n# Should return: PONG\n```\n\n---\n\n### STEP 5: DEPLOY PHASE 7 (1 jam)\n\n#### 5.1 Upload WebSocket files\n```bash\nscp realtime-sync.js user@server:/var/www/cbtmo/\nscp server-websocket.js user@server:/var/www/cbtmo/\n```\n\n#### 5.2 Start WebSocket server\n```bash\nnpm install ws\nnode server-websocket.js &\n```\n\n#### 5.3 Update exam.html\nTambahkan sebelum `</body>`:\n\n```html\n<script src=\"/realtime-sync.js\"></script>\n<script>\n  realtimeSync.connect();\n  window.addEventListener('realtimeUpdate', (e) => {\n    console.log('Real-time update:', e.detail);\n  });\n</script>\n```\n\n#### 5.4 Verify\n```bash\nnetstat -an | grep 8080\n# Should show: LISTEN\n```\n\n---\n\n### STEP 6: DEPLOY PHASE 8 (2 jam)\n\n#### 6.1 Setup Nginx\n```bash\nsudo apt-get install nginx\nsudo cp nginx.conf /etc/nginx/sites-available/cbtmo\nsudo ln -s /etc/nginx/sites-available/cbtmo /etc/nginx/sites-enabled/\nsudo nginx -t\nsudo systemctl restart nginx\n```\n\n#### 6.2 Setup Docker (optional)\n```bash\ndocker build -t cbtmo:latest .\ndocker run -d -p 3000:3000 cbtmo:latest\n```\n\n#### 6.3 Setup Kubernetes (optional)\n```bash\nkubectl apply -f kubernetes-deployment.yaml\n```\n\n#### 6.4 Verify\n```bash\nsudo systemctl status nginx\n# Should show: active (running)\n```\n\n---\n\n### STEP 7: DEPLOY PHASE 9 (30 menit)\n\n#### 7.1 Upload monitoring files\n```bash\nscp performance-monitor.js user@server:/var/www/cbtmo/\nscp error-tracker.js user@server:/var/www/cbtmo/\n```\n\n#### 7.2 Update exam.html\nTambahkan sebelum `</body>`:\n\n```html\n<script src=\"/performance-monitor.js\"></script>\n<script src=\"/error-tracker.js\"></script>\n```\n\n#### 7.3 Setup monitoring endpoint\n```bash\nnode monitoring.js &\n```\n\n#### 7.4 Verify\n```bash\ncurl -X POST http://localhost:3001/api/metrics \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"test\": true}'\n# Should return: {\"success\":true}\n```\n\n---\n\n## ✅ VERIFICATION\n\nSetelah deployment, check:\n\n### 1.
