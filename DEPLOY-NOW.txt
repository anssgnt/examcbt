================================================================================
  DEPLOY OPTION A - GITHUB + NETLIFY UI
================================================================================

STEP 1: CREATE GITHUB REPOSITORY
================================================================================

1. Go to https://github.com
2. Login to your account (or create new)
3. Click "+" icon → "New repository"
4. Fill in:
   - Repository name: cbtmo
   - Description: CBT Optimization - Phase 1-4
   - Visibility: Public
5. Click "Create repository"
6. Copy the HTTPS URL: https://github.com/YOUR_USERNAME/cbtmo.git

================================================================================
STEP 2: PUSH CODE TO GITHUB
================================================================================

Open Command Prompt and run:

cd c:\laragon\www\cbtmo

git remote add origin https://github.com/YOUR_USERNAME/cbtmo.git

git branch -M main

git push -u origin main

Replace YOUR_USERNAME with your GitHub username.

Expected output:
  Enumerating objects: ...
  Counting objects: ...
  Writing objects: ...
  Branch 'main' set up to track remote branch 'main' from 'origin'.

================================================================================
STEP 3: CONNECT TO NETLIFY
================================================================================

1. Go to https://app.netlify.com
2. Login to Netlify (or create new account)
3. Click "New site from Git"
4. Click "GitHub"
5. Authorize Netlify (if first time)
6. Search for: cbtmo
7. Click on repository: YOUR_USERNAME/cbtmo

================================================================================
STEP 4: CONFIGURE BUILD SETTINGS
================================================================================

In Netlify deployment settings:

Build command: npm run build
Publish directory: public

Click "Deploy site"

Wait for build to complete (1-2 minutes)

================================================================================
STEP 5: VERIFY DEPLOYMENT
================================================================================

1. Check Netlify dashboard → Deploys tab
2. Wait for status: "Published"
3. Get site URL: https://your-site.netlify.app
4. Open site in browser
5. Press F12 (DevTools)
6. Check Console tab
   Should see: ✅ All optimization scripts loaded
7. Check Application tab → Service Workers
   Should see: 2 active Service Workers

================================================================================
TROUBLESHOOTING
================================================================================

Build Failed:
  - Check Netlify build logs
  - Check netlify.toml configuration
  - Check package.json build script

Site Not Loading:
  - Check public/ folder has exam.html
  - Clear browser cache (Ctrl+Shift+Delete)
  - Reload page (Ctrl+R)

Service Workers Not Registering:
  - Check browser console for errors
  - Check file paths in exam.html
  - Clear cache and reload

Performance Still Slow:
  - Check DevTools Network tab
  - Check if Service Workers are caching
  - Monitor Netlify Analytics
